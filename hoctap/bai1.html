BÀI 1
INTERNET LÀ GÌ? WEBSITE HOẠT ĐỘNG NHƯ THẾ NÀO?

I. MỤC TIÊU BÀI HỌC

  • Phân biệt rõ Internet và Website
  • Hiểu quá trình truy cập một trang web
  • Nhận diện website tĩnh và website động

II. INTERNET LÀ GÌ?

1. Bản chất của Internet

Internet là một mạng lưới kết nối các máy tính, máy chủ trên toàn thế giới thông qua các giao thức thống nhất. Internet là hạ tầng, không phải là website, cũng không phải là mạng xã hội.

Cần nhớ:
Internet giống như hệ thống đường giao thông; website, email, ứng dụng là các phương tiện chạy trên đó.

2. Internet dùng để làm gì?

  • Truy cập website
  • Gửi – nhận email
  • Lưu trữ và chia sẻ dữ liệu
  • Học tập, làm việc, quản lý

III. WEBSITE LÀ GÌ?

1. Định nghĩa

Website là tập hợp các trang web được lưu trữ trên máy chủ và được truy cập thông qua Internet bằng trình duyệt.

2. Website hoạt động ở đâu?

  • Website nằm trên Server
  • Người dùng truy cập bằng trình duyệt
  • Trình duyệt tải và hiển thị nội dung

IV. KHI GÕ MỘT ĐỊA CHỈ WEB, ĐIỀU GÌ XẢY RA?

  1. Trình duyệt hỏi hệ thống DNS
  2. DNS trả về địa chỉ IP của máy chủ
  3. Trình duyệt gửi yêu cầu đến Server
  4. Server gửi về HTML, CSS, JavaScript, hình ảnh
  5. Trình duyệt hiển thị trang web
Lưu ý quan trọng:
Trình duyệt chỉ hiểu HTML, CSS và JavaScript.

V. WEBSITE TĨNH VÀ WEBSITE ĐỘNG

1. Website tĩnh

  • Nội dung cố định
  • Mỗi trang là một file HTML
  • Không xử lý dữ liệu phía server

2. Website động

  • Nội dung thay đổi theo người dùng
  • Có xử lý phía server
  • Có cơ sở dữ liệu

VI. KẾT LUẬN CỐT LÕI

✔ Internet ≠ Website
✔ Website chạy trên Server, hiển thị trên Trình duyệt
✔ HTML – CSS – JavaScript là nền tảng
✔ Website tĩnh là nền móng của website động

VII. BÀI TẬP

Bài tập 2:
