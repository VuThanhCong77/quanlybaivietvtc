BÀI 4: JAVASCRIPT CƠ BẢN

1. JavaScript là gì?

JavaScript là ngôn ngữ lập trình chạy trên trình duyệt, giúp website tương tác với người dùng. Nếu HTML là khung nhà, CSS là trang trí, thì JavaScript là hành động.

2. JavaScript dùng để làm gì?

  • Xử lý sự kiện (bấm nút, nhập dữ liệu)
  • Thay đổi nội dung trang web
  • Kiểm tra dữ liệu người dùng nhập
  • Tạo hiệu ứng động, thông báo

3. Cách nhúng JavaScript vào HTML

Cách 1: Viết trực tiếp trong thẻ <script>

<script>
    alert("Xin chào JavaScript!");
</script>

Cách 2: Dùng file riêng .js

<script src="script.js"></script>

7. Bài tập thực hành

  1. Tạo nút bấm hiển thị thông báo chào mừng
  2. Tạo biến lưu họ tên và hiển thị ra màn hình
  3. Thử thay đổi nội dung một đoạn văn bằng JavaScript
Ghi nhớ: JavaScript là nền tảng quan trọng để học tiếp các framework và lập trình web nâng cao.
