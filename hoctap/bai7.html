BÀI 7: CẤU TRÚC ĐIỀU KIỆN VÀ VÒNG LẶP

1. Cấu trúc điều kiện (if)

if (điều_kiện) {
    // lệnh thực hiện
} else {
    // lệnh khác
}

Ví dụ:

var tuoi = 20;
if (tuoi >= 18) {
    console.log("Đủ tuổi");
} else {
    console.log("Chưa đủ tuổi");
}

2. Toán tử so sánh

  • == : bằng
  • != : khác
  • > , < , >= , <=

3. Vòng lặp for

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

4. Vòng lặp while

let i = 1;
while (i <= 3) {
    console.log(i);
    i++;
}

5. Bài thực hành

  1. Viết chương trình kiểm tra số chẵn/lẻ
  2. Dùng vòng lặp in ra các số từ 1 đến 10
  3. Kiểm tra tuổi để thông báo đủ/không đủ điều kiện

6. Ghi nhớ

  • Điều kiện giúp chương trình ra quyết định
  • Vòng lặp giúp xử lý công việc lặp lại
  • Đây là tư duy cốt lõi của lập trình
