BÀI 9: HIỂN THỊ DANH SÁCH RA HTML BẰNG JAVASCRIPT

1. Mục tiêu bài học

Kết hợp Mảng + Đối tượng + DOM để hiển thị dữ liệu ra giao diện HTML. Đây là kỹ năng cốt lõi khi xây dựng website động.

2. Dữ liệu mẫu (mảng đối tượng)

let danhSach = [
 { hoTen: "Nguyễn Văn A", tuoi: 40, chucVu: "Bí thư" },
 { hoTen: "Trần Văn B", tuoi: 35, chucVu: "Phó Bí thư" },
 { hoTen: "Lê Văn C", tuoi: 30, chucVu: "Đảng viên" }
];

4. Phân tích tư duy

  • Dữ liệu lưu trong mảng đối tượng
  • Dùng vòng lặp duyệt từng phần tử
  • Ghép HTML bằng JavaScript
  • Đưa kết quả vào DOM
Ghi nhớ quan trọng:
Hầu hết website thực tế đều hoạt động theo mô hình: Dữ liệu → Xử lý → Hiển thị

5. Bài thực hành

  1. Thêm một người mới vào mảng
  2. Thêm cột Email vào bảng
  3. Đổi bảng sang hiển thị danh sách bài viết
