HƯỚNG DẪN CẬP NHẬT DỮ LIỆU

Thay đổi chữ chạy trang Index & cập nhật nội dung Trang Văn bản

I. Thay đổi chữ chạy trên trang Index

1. Mục đích

Phần chữ chạy dùng để thông báo nhanh các nội dung nổi bật như: chủ trương, sự kiện, thông báo quan trọng… Việc thay đổi được thực hiện thông qua file cấu hình, không cần chỉnh sửa mã HTML.

2. Các file liên quan

  • index.html – Trang chủ hiển thị
  • site_config.json – File cấu hình chữ chạy

3. Cách thay đổi nội dung chữ chạy

  1. Mở file site_config.json
  2. Tìm dòng:
"marquee_text": "Nội dung chữ chạy hiện tại"

Thay nội dung trong dấu ngoặc kép bằng nội dung mới.

"marquee_text": "Nhiệt liệt chào mừng kỷ niệm ngày thành lập phường Lưu Kiếm"

Lưu file và tải lại trang index.html để xem kết quả.

Lưu ý:
– Không xóa dấu ngoặc kép
– Không xuống dòng trong nội dung chữ chạy
– Tránh ký tự đặc biệt lạ

II. Cập nhật nội dung Trang Văn bản

1. Mục đích

Trang Văn bản dùng để hiển thị các quy định, hướng dẫn, văn bản chuyên môn. Nội dung được quản lý riêng thông qua file JSON.

2. Các file liên quan

  • vanban.html – Trang hiển thị văn bản
  • admin.html – Trang chỉnh sửa nội dung
  • content.json – File lưu nội dung văn bản

3. Các bước cập nhật nội dung

  1. Mở file admin.html
  2. Nhập Tiêu đề trang
  3. Nhập Nội dung văn bản (có thể sử dụng HTML)
<p>Quy định số 296-QĐ/TW ban hành ngày...</p>
<p><b>Điều 1.</b> Phạm vi điều chỉnh...</p>
  1. Bấm nút “Tạo / Cập nhật file content.json”
  2. Ghi đè file content.json vào thư mục chứa vanban.html
  3. Mở lại trang vanban.html để kiểm tra
Lưu ý khi nhập nội dung:
– Không chèn thẻ <script>
– Nên dùng <p>, <b>, <br>
– Có thể soạn trong Word rồi dán vào, sau đó chỉnh lại cho gọn

III. Một số lỗi thường gặp

  • Không hiển thị nội dung: kiểm tra file content.json đã ghi đè đúng chưa
  • Chữ chạy không đổi: kiểm tra đã lưu site_config.json và tải lại trang

IV. Kết luận

Hệ thống quản lý nội dung website được thiết kế đơn giản, dễ sử dụng, không yêu cầu kiến thức lập trình, phù hợp vận hành lâu dài cho cổng thông tin, tuyên truyền và văn bản chuyên môn.
