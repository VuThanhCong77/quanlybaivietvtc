Bước 1: Xuất file JSON

  • Mở trang soanbai.html: Nhập tiêu đề khoảng 30 từ; Mô tả nội dung khoảng 200 từ; Chọn chuyên mục; Nhập nội dung bài viết; chèn ảnh đại diện "tên thư mục/tên tệp.jpg hoặc png
  • Cuộn xuống cuối trang: Lưu bài viết
  • Nhấn “Xuất file JSON (Sao lưu dữ liệu)”
  • * Ghi chú: Nên chia nhỏ tệp posts_data.json "5 bài viết/posts_data.json" để không bị quá dung lượng 5mb, sau này dễ sửa chữa

    • + Kích thước hình ảnh minh họa: 300×188 pixel (px)

    + Kích thước hình ảnh trong trang bài viết và trang ảnh: 800×600 pixel (Dung lượng ảnh dưới 200 KB)

Bước 2: Gộp file JSON

  • Mở file merge_posts_json.html bằng trình duyệt
  • Chọn 3 file posts_data.json
  • Bấm “Gộp & tải file”
  • Nhận file mới: posts_data.json
  • ✔ Không lỗi
  • ✔ Không cần cài thêm gì
  • ✔ Dùng được trên mọi máy tính
  • Mỗi file JSON phải có dạng:
  • [
  • {
  • "id": "1769228083194",
  • "title": "Tiêu đề bài viết",
  • "category": "baiviet",
  • "description": "Nội dung bài viết",
  • "shortDescription": "Mô tả bài viết",
  • "date": "2026-01-24",
  • "author": "Admin",
  • "thumbnail": "images/35.jpg",
  • "fileData": "",
  • "fileName": "",
  • "likes": 0
  • }
  • ]
  • 📌 Không được:
  • Có dấu phẩy thừa
  • Không phải mảng [ ]
  • Trùng id (khuyến nghị)
  • Gợi ý nâng cấp (nếu cần)

    • ✅ Tự động sắp xếp theo date mới nhất

    ✅ Tự động đánh lại id

    ✅ Lọc theo category

    ✅ Gộp + đẩy thẳng lên GitHub
